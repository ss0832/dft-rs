# Oracle environment

- PySCF 2.14.0, NumPy 2.5.1
- GIAO NMR additionally uses pyscf-properties 0.1.0 from official commit
  `4eee5a430fb47eca5962f36fdcaf75c2b87e7ede`; the CSV pins the installed
  RHF/RKS source hashes, libxc 7.0.0, basis/geometry hashes, and grid metadata.
- Generated by tools/oracle/gen_integrals.py (WSL Ubuntu)
- NMR generated by tools/oracle/gen_nmr.py (WSL Ubuntu); DFT grid levels 8/9
  must agree within 0.005 ppm for total, diamagnetic, and paramagnetic parts.
- Regeneration is manual; diffs are reviewed like code.
